**Step 2 — Build tooling (`scripts/build.py` + `Makefile`):**
- `scripts/build.py`:
  - `LUMINA = /home/horux/projects/lumina/target/release/lumina-cli` (constant at top, comment explaining how to override).
  - `build.py render` — glob `calc/*.lsf` + `coding/*.lsf`, for each run `[LUMINA, --scene, path, --output, out/<series>/<name>.mp4, --format, mp4, --backend, skia]` with `cwd = content root` (so relative font paths resolve). Stream stdout/stderr live. Stop on first failure.

  - `build.py watch --scene <path>` — run `[LUMINA, --scene, path, --watch, --output, out/preview/]`.
  - `build.py clean` — `rm -rf out/`.
  - argparse subcommands; colorized OK/FAIL output.
- `Makefile`:
  - `make all` → `python3 scripts/build.py render`
  - `make check` → `python3 scripts/build.py check`
  - `make watch SCENE=calc/01-*.lsf` → watch one
  - `make clean`
  - `make one SCENE=...` → render one scene
  - default target prints help.

## Risks & mitigations
- **Risk:** lumina's `LaTeX` object uses Unicode substitution, not real TeX — complex equations may render crudely. **Mitigation:** keep equations simple (`d/dx`, `x^n`, `\frac`, `\sqrt`), test render early in Step 4, fall back to pre-formatted `Text` if a glyph is unsupported.
- **Risk:** Vertical 1080×1920 wasn't in the shipped examples (they're 16:9). **Mitigation:** canvas is just width/height ints; nothing in the engine assumes aspect ratio. Smoke-test with one calc scene at full size before authoring the rest.
- **Risk:** `Plot` math is limited to sin/cos/tan/sqrt/abs/exp/ln. **Mitigation:** episodes 1–3 use `x^2`, `x^n`, `sin(x^2)` — all within supported set (`^` is pow operator in evalexpr; will verify in Step 4 smoke test).
- **Risk:** If the prebuilt `lumina-cli` is stale relative to the current schema, scenes using newer features may fail validation. **Mitigation:** Step 0 smoke test catches this; I'll author to the schema I can see in the existing examples.
