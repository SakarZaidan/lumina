## Areas and who to ask

Until there are enough maintainers for this to mean anything, everything routes
to the lead. The areas are listed because the labels use them and because it
makes the shape of the project legible:

| Area | Scope |
|---|---|
| `area/schema` | `lumina-schema` — the LSF wire format. Changes need an RFC |
| `area/core` | `lumina-core` — timeline, easing, interpolation, events, validation |
| `area/renderer` | `lumina-renderer` — both backends, `common/`, the parity suite |
| `area/text` | `lumina-text` — fonts, glyph rasterisation, layout |
| `area/export` | `lumina-export` — encoding and the ffmpeg pipeline |
| `area/server` | `lumina-server` — the HTTP API. Changes need an RFC |
| `area/wasm` | `lumina-wasm` — the browser runtime and hit-testing |
| `area/cli` | `lumina-cli` |
| `area/sdk` | Python and JavaScript SDKs |
| `area/ci` | CI, releases, supply chain |
